# WatchMemo · 首轮真机验证清单（v0.1.0 功能版）

> 目的：一次安装，尽量把整条链路验证完：**手表录音 → 同步 → 中文转录 → 搜索 / 回放 → AI 摘要 / 每日回顾 / 问问**。
> 每项记录「通过 / 不通过 / 现象」。不通过时到 iPhone「设置 → 诊断」导出日志。

## 0. 安装

- [ ] 用 Sideloadly / AltStore 等工具，以自己的 Apple ID 对 `WatchMemo-unsigned.ipa` 重新签名并安装到 iPhone。
- [ ] 打开 iPhone「Watch」App → 我的手表 → 找到 WatchMemo → 安装到手表。
- [ ] 如签名工具提示 HealthKit 能力无法签名：先不测 M3（体能训练会话），告诉我，我把 HealthKit 做成可选。

## 1. 手表录音（阶段 A 的核心项，详见《阶段A-技术验证计划》）

- [ ] 首次点击红色大按钮：弹出麦克风授权 → 允许后开始录音，有震动反馈。
- [ ] 录音中显示“录音中 · 可放下手腕”，暂停 / 继续 / 结束都有震动；结束前有确认。
- [ ] 放下手腕 10 分钟（S2），分别用三种保活方案各录一次，记录哪种能录满。
- [ ] 回到首页能看到“今天 N 条 · 总时长”和“已全部同步到 iPhone”。

## 2. 同步

- [ ] iPhone「记录」页按天出现新录音；未结束时显示“接收中”，结束后“完整”。
- [ ] iPhone 开飞行模式录 3 分钟，关闭后自动补齐，没有重复记录。
- [ ] 「设置 → 诊断 → 同步与连接」：缺失分段合计 = 0。

## 3. 中文转录

- [ ] 首次收到录音时弹出「语音识别」授权，允许后自动开始转录（首页显示“正在转录… 剩余 N 段”）。
- [ ] 「设置 → 转录」里“此语言支持设备端识别”显示 **是 / 否**：______
- [ ] 飞行模式下新录一段，是否仍能转录：______（判断能否完全离线）
- [ ] 三类样本效果（主观 1–5 分）：纯普通话 ___ / 中英混说 ___ / 嘈杂环境 ___
- [ ] 录一段“完全不说话”的 1 分钟：应被判为“静音跳过”（详情 → 详情页签里看“有声 %”）。
- [ ] 正常说话的分段“有声 %”大约是多少：______（用来校准静音阈值）
- [ ] 转录速度：详情页签里每段“耗时”约 ___ 秒 / 分钟音频。

## 4. 回放与搜索

- [ ] 录音详情底部播放条：播放、拖动、±15 秒、倍速都正常；多个分段连续播放没有明显卡顿。
- [ ] 点击转录里的任意一句，从这句话开始播放；正在播放的句子有高亮。
- [ ] 「搜索」输入一个说过的词：能找到，关键词高亮；点结果直接定位到那句话。
- [ ] 时间范围筛选（今天 / 近 7 天 / 指定日期）正常；「记录」页右上角日历可按日期查看。

## 5. AI（需要自己的 API Key，推荐先用 DeepSeek 或通义千问）

- [ ] 「设置 → AI」开启云端 AI → 模型服务 → 选服务商、粘贴 Key、保存 → 测试连接显示 ✓。
- [ ] 录音详情 → 摘要 → 生成摘要：发送前弹出告知（字数、目标域名）；生成后有标题、概述、要点、待办、待解决。
- [ ] 勾选待办；「记录」左上角清单图标能看到所有待办。
- [ ] 「记录」每天第一行“每日回顾” → 生成：有一句话概括、高光、回顾、待办。
- [ ] 「问问」：问“今天我都聊了些什么？”，回答能引用具体录音，点引用能跳到原文。
- [ ] 关闭云端 AI 后，录音、转录、搜索、回放仍正常（验收标准 7）。

## 6. 删除与清理

- [ ] 删除一条录音：音频、转录、摘要、待办都消失；搜索不再出现。
- [ ] 「设置 → 存储」显示音频 / 文字占用；把保留期设为 7 天后点“立即清理”，超过 7 天且已转录完的录音变成“仅文字”，文字仍可搜索。
